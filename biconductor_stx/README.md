# Overview of the contents
This directory contains the .def and the .yml files to build singularity/apptainer containers for spatial transcriptomics data analysis using Bioconductor packages. 

# Packages 
Some of the main packages are listed below -
1. I/O and basic manipulation 
- SpatialExperiment
- SpatialFeatureExperiment
- Voyager
- HDF5Array

2. QC and normalization
- SpotSweeper
- SpaNorm
- scater
- scran

3. Spatially variable gene selection
- nnSVG
- batchSVG

4. Spatial domain identification/clustering
- BayesSpace
- Banksy

5. Annotation
- SingleR

6. Visualization
- ggspavis
- patchwork

Rstudio server can also be launched using this container.
